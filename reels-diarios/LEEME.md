# Reels diarios en 3D · desde el 26-11-2026

Cada día a las 19:30 Claude hace un reel 3D con Blender que se publica al día siguiente a las 19:00. Cada reel tiene su carpeta `AAAA-MM-DD_tema/` con:

| Archivo | Qué es |
|---|---|
| `LEEME.md` | Qué vídeo es, de quién fue la idea, cuándo se publica y enlaces. |
| `prompt_AAAA-MM-DD.md` | El prompt de producción que escribió ChatGPT tras entrevistar a Claude (guion, planos, Blender, portada, voces…). |
| `scripts/` | El código de Blender de ese vídeo. |
| `video-sin-voz_AAAA-MM-DD.mp4` | Lo que sale de Blender, sin sonido. |
| `portada_AAAA-MM-DD.png` y `portada-cuadrada_AAAA-MM-DD.png` | Portada vertical y cuadrada. |
